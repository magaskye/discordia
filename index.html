PERGUNTAS FREQUENTES

Antes de entrar no universo.

Tire suas dúvidas sobre versões, atualizações e desenvolvimento.

Já posso baixar o Discórdia?

A RC5 está em testes privados. Quando existir uma Release pública aprovada, os links de download aparecerão automaticamente nesta página.

Qual é a diferença entre Estável e RC?

Estável é para versões aprovadas. RC (Release Candidate) é um programa opcional para testers, com possíveis bugs e recursos experimentais.

O Discórdia terá atualização automática?

O instalador Windows tem um atualizador em validação. Ele deverá consultar Releases oficiais, mostrar as novidades e permitir adiar, sem encerrar chamadas sem confirmação. O portátil oferece link para download, não troca silenciosa do EXE.

O SFU já transmite vídeo?

A autorização de sala já foi testada. O envio e recebimento de vídeo pelo SFU ainda estão sendo desenvolvidos e não podem ser considerados homologados.

Como relatar bugs e sugestões?

Use a área de Issues do GitHub por enquanto. Ela é pública: não envie senhas, tokens, dados pessoais ou imagens sensíveis. O formulário privado com antispam ainda está no planejamento.

CONSTRUINDO JUNTOS

Tem uma ideia para o Discórdia?

Erros e sugestões ajudam o projeto a crescer. Os relatos publicados no GitHub são visíveis a outras pessoas; não inclua dados sensíveis.
