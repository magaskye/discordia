Privacidade e desenvolvimento.

Informações preliminares do site. O Discórdia Desktop ainda está em testes. Esta página não substitui a política completa de privacidade do aplicativo, que precisa ser finalizada antes de uma distribuição estável pública.

1. Sobre este site

Este site é estático e utiliza o GitHub Pages como serviço de hospedagem. Não inserimos aqui formulários de cadastro, cookies analíticos próprios, ferramentas de publicidade ou scripts de rastreamento de terceiros. O provedor de hospedagem pode processar dados técnicos de acesso segundo seus próprios termos.

2. Consulta das versões

O navegador consulta a API pública do GitHub para descobrir Releases oficiais e seus arquivos de download. Ao acessar a página, o GitHub pode receber dados técnicos dessa requisição. Consulte a declaração de privacidade do GitHub.

3. Relatos de bugs e sugestões

O canal inicial utiliza Issues públicos do GitHub. Relatos e anexos podem ficar visíveis a outras pessoas. Não envie senhas, credenciais, tokens, informações pessoais de terceiros ou imagens com dados sensíveis. Um formulário privado com antispam ainda não está disponível.

4. Aplicativo Discórdia Desktop

O aplicativo utiliza autenticação e serviços para mensagens, perfis e presença, além de tecnologias de voz e vídeo. A política específica do aplicativo deverá detalhar dados tratados, fornecedores, retenção e direitos dos usuários após revisão. Não estamos afirmando que todas as comunicações possuam criptografia de ponta a ponta.

5. Revisões

Este conteúdo pode ser atualizado conforme o projeto evoluir. Revisão desta página: 19 de outubro de 2026.
